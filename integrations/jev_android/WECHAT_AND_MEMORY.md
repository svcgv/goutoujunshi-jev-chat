# 微信一对一、对象绑定和悬浮球

这是本 fork 新增的 **实验性 Android 能力**，不是对所有手机或微信版本的兼容承诺。请安装本地新构建的 APK；上游旧 Release 不包含这些改动。尚未在你的手机、微信版本上验收。

## 使用步骤

1. 在 App 中配置模型接口，授予无障碍和悬浮窗权限，打开助手总开关。
2. 进入微信或 QQ 的**一对一**聊天，点击或长按悬浮球。
3. 点「绑定对象 / 记忆设置」，新建对象或选择已有档案。确认当前聊天身份；如需历史记忆，勾选保存已核对消息。授权会开启历史总开关，但只有单独同意记忆的绑定才会记录。
4. 点「分析当前对话」。节点可读时直接核对文字，否则尝试无障碍截屏。失败页可以选择「自动补录会话历史」或「导入聊天截图」。
5. 「自动补录会话历史」是**一次由用户主动触发的有界任务**：先回到会话底部，再自动向上翻页读取最近的消息，默认 50 条（可选 10–100）。跨屏的长消息会跨帧拼接；采集中点一下悬浮球可随时停止，结束后逐条核对。它只在这一次任务里自动滑动，不做后台常驻补录，也不上传或保存截图。
6. 补录优先读取无障碍节点原文；节点读不到时改用本机 OCR。若系统不允许无障碍截屏，会请求一次投屏授权，并在**本次补录**期间按需取帧（会话结束时立即释放，不后台常驻录像）。OCR 无法判断说话人，会标成「待确认」，必须逐条确认为「我」或「对方」。
7. 补录过程中每一步都会复核前台应用与会话身份：切换联系人、退到其他应用或进入群聊会立即停止，不会把别人的消息混进来。悬浮通知或悬浮键盘压在消息区域时会跳过该帧并等待恢复；连续等待超时则停止并给出原因。
8. 导入截图走系统文件选择器，不申请整个相册访问权限。两个入口默认使用本地 ML Kit，不上传原图。
9. 备用入口取得图片后再次确认目标对象，再核对文字。整屏 OCR 无法可靠识别说话人时显示「待确认：」，必须改为「我：」或「对方：」才能继续；它不会假装所有文字都是对方说的。
10. 点「确认原文并分析」后，先按记忆设置保存文字，再发起模型请求。即使密钥未配置或网络失败，已经成功保存的文字仍保留。
11. 再次进入能识别标题的已绑定窗口，悬浮面板显示对象和本机历史条数，下一次分析自动注入该对象近期历史。也可点「查看对象历史」。

## 身份与记忆边界

- 绑定使用**应用包名 + 精确会话标题 → 对象 ID**，不再自动按昵称/别名选第一个人。QQ 和微信的同名默认不合并；只有你明确选择同一对象才共享档案。
- **同一应用内两个完全同名窗口、切换微信账号或应用分身，无法靠标题可靠区分。请设置唯一备注，或解除旧绑定后重新绑定。此版本不支持多账号自动隔离。**
- 改备注后不会自动关联旧对象；选择原对象重新绑定即可。标题读不到时必须手动填写本轮称呼并确认，不能继承上一个人的标题；这种场景下每轮重新确认，不保证重开自动识别。
- 已有联系人、笔记和历史不删除，但旧别名匹配不再直接用于加载上下文，需首次重新绑定确认。
- 记忆总开关关闭时不保存或向模型注入历史；每个绑定也可单独暂停。解除绑定不删除原历史；「清空此对象历史」有二次确认，删除对象会清理相应绑定及历史。
- 每对象最多保留 300 条，默认注入最近 30 条（设置可调整），仍受已有上下文字符预算约束。连续重复屏幕与相邻重叠消息去重；没有消息 ID，不能保证跨多张重叠截图精确重建完整历史。
- 保存时间是采集确认时间，不是微信原消息发送时间。不读取微信数据库，不导出完整记录，不自动翻页。
- 仅支持一对一。已识别的群聊会拦截；无法自动判断时用户必须确认不是群聊。原文、对象、消息归属都要核对。
- 本地联系人、绑定和历史保存在应用私有 JSON，**未额外加密**。选择分析后，档案和所选历史将发送给已配置的代理/模型；不要导入无权使用的会话。
- `FLAG_SECURE`、系统厂商限制或黑屏不能绕过。请使用聊天应用/系统允许的普通截图，无法截图时不要尝试破解。

## 悬浮球

- 自由拖拽，不强制吸边，拖动结束即保存位置；隐藏重开、服务重启后恢复。
- 展开面板不覆盖已保存的悬浮球位置；展开时拖动会收起面板并更新位置。
- 旋转或屏幕大小改变时将旧坐标限制到可见范围，避免悬浮球跑出屏幕。
- 点击展开，长按打开操作菜单；拖动不会误触发点击或长按动作。

## 真机验收清单

1. QQ 与微信对象 A/B 交替进入，历史和结果不串人；返回列表时旧结果清空。
2. 微信不同版本节点不可读时，悬浮球仍可打开备用入口。
3. 系统授权允许、拒绝、取消、返回别的聊天、息屏/旋转、关闭总开关，都不留下持续录屏或旧结果。
4. 导入清晰的单屏截图，确认对象和每条说话人；取消核对不写历史。
5. 相同截图连续确认不重复入库；下一次打开读取旧上下文；模型请求失败仍能查看已保存记录。
6. 开关对象记忆、全局记忆，解除绑定、清空历史、删除联系人，效果与提示一致。
7. 悬浮球拖到屏幕四角和中央，展开/收起、长按再拖、重启与旋转后仍可见，且不会回到旧位置。
8. 生成回复只提供复制或安全填入，不自动发送。
