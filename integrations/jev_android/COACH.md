# Android 完整军师咨询

本次 Android 升级在原有悬浮回复之外增加三项能力：

- **发起聊天**：初识、日常主动或重新联系。未知共同经历不会被编造。
- **暂时离开会话**：只生成本轮暂时暂停聊天的自然话术，不编造具体借口，也不结束关系或减少投入。
- **问军师**：独立于微信、悬浮窗和无障碍权限的多轮咨询，覆盖情绪支持、事实梳理、主动推进和冲突修复。

悬浮窗空闲页和已有结果页都有快捷入口。咨询页中的话术默认只复制，不自动填入或发送。需要回填微信时，仍从原悬浮回复入口操作，并经过目标窗口验证。

## 模型选择

先在「设置 → 服务与模型」集中添加服务、地址、密钥和多个模型。普通回复使用全局回复模型；发起聊天、暂时离开会话和问军师默认跟随该模型，也可在「设置 → 功能模型」中分别覆盖。所有覆盖只保存模型引用，不复制地址或密钥，修改服务后自动生效。

全局判断选择聊天模型时，三个功能先使用该模型判断，再使用各自生效的生成模型；选择 Jev 时，保留旧 Jev 兼容路径，新军师任务由功能实际生效的生成模型承担分析与生成。设置页会显示每个功能实际使用的服务与模型。

## 三类保存授权

升级后有三类互不替代的本机数据：

1. **聊天历史**：继续由设置里的“记录聊天历史”和服务中的绑定同意控制。
2. **精简长期记忆**：必须另行明确同意。只保存短字段、关系阶段、关键事件和带置信度的暂定解释；可查看、纠正、暂停、撤销、撤回和删除。
3. **咨询原文**：默认关闭。开启后才保存咨询页的问题和回答，可单独清空。

已有联系人、绑定和聊天历史不迁移为精简记忆，也不会自动继承旧同意。聊天原文和密钥不会写入日志；发送给模型的上下文仍由用户配置的服务处理。

## 质量与安全规则

统一编排层按任务先判断主策略，再生成咨询和话术。资料范围优先包含当前已核对原话、用户诉求、明确边界和当前对象档案；长历史会压缩并标注，不把摘要当核实事实。

明确要求停止联系会阻止开场、普通回复和“最后一句”。一次性拒绝时间不会被升级成关系拒绝；历史停止联系边界会持续生效。威胁、跟踪、强迫、勒索、暴力、自伤要挟等进入安全优先路径。

模型结构化输出无效时最多重试一次；仍失败会保留输入并明确报错。咨询页关闭、旋转或发起新任务时，旧请求会取消，结果不能重新显示或写记忆。

## 测试与效果对照

```bash
cd integrations/jev_android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

三个方法主题、章节检索、来源清单、精简记忆、咨询原文、取消和边界场景都有单元测试。`app/src/test/resources/coach_benchmark_cases.json` 包含 30 个合成场景，覆盖开场、收尾、回复、咨询和安全。

使用实际的 OpenAI 兼容模型运行对照时，将密钥放在环境变量，不写入仓库：

```bash
export OPENAI_API_KEY='你的客户端密钥'
python3 tools/coach_benchmark.py \
  --base-url http://127.0.0.1:8317/v1 \
  --model '你的模型 ID' \
  --repeats 2 \
  --out /tmp/coach_benchmark_report.json
```

脚本比较“当前提示”“改进编排”和原 skill 三组输出。报告中的客观检查只验证可确定的边界和安全词；自然度、目标适配、事实忠实度、行动可执行性和后续分支需要隐藏来源后人工盲评。没有运行真实模型时，不宣称量化提升或恋爱成功率。

## 已知限制

- 多人比较和角色演练不在此版本范围。
- 不同模型对 JSON 的遵守程度不同；解析失败会显示错误，不生成半截话术。
- 真机微信版本、悬浮窗和输入框行为仍须逐设备验收。
- 精简记忆是决策辅助，不是对人格、爱意、忠诚或未来意图的事实认定。
