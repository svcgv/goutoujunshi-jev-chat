# 狗头军师 Jev Chat · Android 源码适配

本目录基于 [Jev Android](https://github.com/jev-chat/jev-chat-jarvis) 的聊天应用采集、ML Kit 中文离线 OCR、悬浮窗、Jev 判断和候选填入链路。已改为独立应用 ID `com.goutoujunshi.chat`，接入狗头军师的自然口吻、事实与推测边界、下一步和停止条件。原文与说话人仍需用户核对；程序检查可见对话里对方最后一条消息中的部分停止联系表述，自己的后续回复不会解除拦截。不可见的历史和未匹配的表述仍需用户核对。程序不自动发送。

**状态：提供 Android 11+ 调试预览 APK，真机验收尚未完成。本 fork 已新增实验性微信一对一读取、自动补录会话历史和截图导入，但不保证所有设备兼容。** QQ、X、飞书等聊天应用路径仍需在对应设备上验证。首次安装后的助手和自动分析默认关闭，需在界面中主动开启。本目录不包含上游现成 APK。

本 fork 的 Android 已增加 **完整军师咨询、发起聊天和暂时离开会话入口**：见 [Android 完整军师咨询](COACH.md)。咨询页可独立于微信和悬浮权限使用；精简长期记忆与咨询原文保存需分别明确同意，且都可暂停、撤销和删除。

本 fork 的 Android 已增加 **服务与模型统一配置**。先在设置页进入「服务与模型」，为一个服务的地址和密钥添加多个模型；再回到设置页选择判断、回复和视觉模型。OpenRouter 可在同一服务下同时保存 Jev 和聊天模型，其他服务按各自支持的协议显示。兼容服务支持从 `/models` 拉取、搜索和多选导入，也可手动添加。

「发起聊天」「暂时离开会话」「问军师」默认跟随全局回复模型，也可分别指定生成模型。服务地址或密钥修改后，所有引用它的接口和功能自动使用新值；被引用的服务或模型不能直接删除。旧版判断、回复和视觉配置会在首次启动时迁移，原来的同源密钥复用结果会保留。云端识图会发送聊天区域截图并产生服务用量；识别后的对话仍须核对原文和说话人。

## 本 fork：微信、绑定与悬浮球

使用方法与验收清单见 [微信与对象记忆](WECHAT_AND_MEMORY.md)。首次手动绑定窗口和对象；明确开启记忆后只保存核对过的文字，重开已识别窗口自动带入。悬浮球可自由拖动并保存位置。旧联系人不自动按昵称合并，需重新绑定确认。自动补录只读取屏幕上可见的文字，不绕过安全窗口，也不保存或上传截图。

## 2026-10-06：安卓流程与 DeepSeek 修复

- **核对与取消：** 隐藏助手、关闭总开关或切换会话会清掉旧核对状态，取消等待焦点、后台任务和过期显示回调。HTTP 连接会尝试断开，后续请求不会继续；已经发给服务的请求无法撤回。
- **DeepSeek 上下文：** 判断、标签轮换、候选排序、详情和回复解释使用当前联系人关系、阶段、目标、背景和选定历史；联系人关系优先于全局默认关系。
- **候选校验：** 只接受最多三条、每条最多四十字的完整 JSON 字符串数组。错误说明、对象、数字和截断输出不会成为填入内容；显示错误后可重试。
- **会话与建议：** 不同标题的会话分别去重，补齐七种中文策略建议。对方要求停止联系后，即使自己又发了消息，也保持候选拦截；对方再次主动发消息后按新一轮判断。
- **OCR 与配置：** OCR 自动分析开关进入实际流程；策略测试读取当前表单的回复地址和密钥，无需先保存。跨服务密钥仍不共用。
- **回归测试：** 新增核对状态取消、旧结果失效、HTTP 请求取消、候选格式、联系人上下文、会话身份和明确边界测试。

## 安装与配置

从[最新 Release](https://github.com/svcgv/goutoujunshi-jev-chat/releases/latest)下载 `goutoujunshi-jev-chat-0.1.11-preview-debug.apk`，在 Android 11 或更新版本上允许系统安装此来源的应用后安装。旧版调试 APK 与新版可能由不同的临时调试证书签名；如提示签名不一致，需卸载旧包再安装，本机应用数据会随卸载清除，先记录好需要保留的设置。打开应用，配置判断和回复接口，按提示授予无障碍、悬浮窗权限，再主动开启助手。应用只生成草稿，由你决定是否发送。

进入「设置 → 服务与模型」新增一个服务，填写地址和密钥，再从 `/models` 拉取或手动添加模型。返回设置页后，分别选择判断模型、回复模型和视觉模型；视觉模型必须标记“支持图片”。正式使用前点击「保存全部设置」。测试按钮使用当前选择创建临时配置，不会替换已保存关联。识图方式仍可独立选择本地 ML Kit 或视觉模型。

## 手动识别一轮对话

QQ、X、飞书有专门的采集适配；Soul 等其他应用使用手动截图入口：

1. 开启助手后，打开目标聊天应用，保持要分析的对话可见。
2. 长按「军师」悬浮球，选择「自动补录会话历史」，确认条数后自动读取最近 50 条；或选择「截屏识别一次」只读当前一屏。
3. 在核对页修改识别原文与双方归属，每行使用「我：」或「对方：」开头。
4. 点「确认原文并分析」，等待原聊天应用焦点恢复，再查看判断与候选。
5. 复制候选，或点击「填入」。未专门适配的应用无法验证输入框，会退回复制；已有草稿也会保留。发送始终由你手动完成。

## OCR 自动识别与手动入口

「OCR 模式自动分析」关闭时，专门适配应用的自动 OCR 识别完只显示悬浮球；点击「分析当前对话」才打开原文核对页。开启后，最新消息来自对方时自动打开核对页。所有模型分析仍需用户点击确认。

长按悬浮球选择「自动补录会话历史」或「截屏识别一次」都属于主动操作，不受自动开关限制，识别后直接打开核对页。「自动补录」会先回到会话底部再向上翻页，默认收集 50 条去重后的消息，跨屏长消息会拼接为一条；采集中点一下悬浮球即可停止。本地全屏 OCR 默认把消息标为对方，需要手动纠正双方归属；视觉模型识别也需要核对。

## 仍需实机验证的范围

- Android 版仍不支持微信；QQ、X、飞书和其他应用的截图、焦点及输入框行为需要对应设备验证。
- 通用 OCR 应用无法验证输入框，会退回复制；相同标题、无法读取标题的会话仍需要用户核对当前对象。
- 云端视觉和策略模型的接口能力、费用、实际输出与 token 权重支持情况由所选服务决定，本轮使用离线响应和自动测试验证逻辑。
- 调试 APK 使用临时签名，旧包可能不能直接覆盖安装。真机安装与权限授予仍需用户验收。
- 当前停止联系拦截依据可见对话中对方最后一条消息及有限表述，不能替代完整历史和人工判断。

## 从源码构建

要求 Android 11+，构建机须安装 JDK 17、Android SDK 35。进入本目录后运行：

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

成功后调试包在 `app/build/outputs/apk/debug/`。应用先集中维护服务与模型，再在设置页关联判断、回复和视觉接口；功能级生成模型可继承全局回复模型。请仅在自己的设备和有权查看的对话中使用。数据使用见仓库根目录 [说明](../../PRIVACY.md)。
